# 夜行赛道

一款可离线运行的单人 3D 竞速游戏，从雨夜街头驶向森林、峡谷与冰湖。Three.js + Vite + 原生 JavaScript，车辆、路线、规则、驾驶控制与 AI 均为本项目编写。所有车辆、城市、自然地形、材质、音乐和音效由本地代码生成；字体和依赖打包到项目中，没有素材外链。

## 开始游戏

Windows 双击 **启动游戏.bat**。启动器检查 Node.js、必要时安装依赖并构建，检查并复用本项目服务，自动选用 5178–5208 范围内可用端口，验证 HTTP 后打开浏览器。不会停止其他项目，也不会修改全局防火墙。

已提供 `dist` 生产构建时，只需要 Node.js 22 或更新版本，运行不需要联网。若首次缺少构建产物与依赖，安装依赖需要联网。

```powershell
cd D:\AnLi\夜行赛道
npm ci --include=optional
npm run build
npm start
```

电脑默认访问 `http://localhost:5178`，冲突时以启动器打印的地址为准。手机或平板与电脑连接同一局域网，使用启动器打印的实际 IPv4 地址。VPN、虚拟网卡、访客网络隔离可能使部分地址无法使用；选实际 Wi-Fi/以太网对应的地址。启动器每次读取当前网卡地址。

开发：`npm run dev -- --port 5188 --strictPort`。开发地址与生产地址端口不同，本地存档也分别独立。

## 驾驶

| 操作 | 键盘 | 手机和平板 |
|---|---|---|
| 加速 | W / ↑ | 油门 |
| 刹车 / 倒车 | S / ↓，停下后继续按可倒车 | 刹车 |
| 转向 | A D / ← → | 左侧拖动转向区 |
| 手刹漂移 | 空格 | 手刹 |
| 氮气 | Shift | 氮气 |
| 安全复位 | R | 左侧复位按钮 |
| 暂停 / 继续 | Esc | 右上暂停按钮 |

刹车优先于油门和自动油门。转向经过平滑处理，速度越高转向角越小。漂移需要速度、转向与手刹共同作用；车身朝向和实际速度方向分开计算。松开手刹会恢复轮胎抓地，反打可以调整侧滑。氮气在松开按钮后立即停止，暂停时不会消耗。

触屏支持多点同时按压，抬起一个手指不会释放另一个。设置中可在左侧转向轮盘与左右箭头按键之间切换，默认使用轮盘；转向方向与键盘统一。触屏自动油门仅用于触屏设备。手机和平板必须横屏游玩；竖屏打开时会显示“请横屏游玩”提示并锁住游戏输入，转为横屏后自动恢复。横屏提示、主菜单和暂停页均提供“全屏游玩”按钮，设置中可关闭按钮显示。浏览器允许全屏 API 时通过按钮进入或退出全屏，并会尝试请求横屏锁定；如果浏览器拒绝全屏请求，会显示提示且保留横屏拦截。

首次锦标赛先进入五步实际驾驶教学，可以跳过；主菜单可以重看。提前刹车、稳住出弯比长时间贴墙更快。

近光灯实际照亮场景，照明范围随车头转向，有柔和边缘和上方截止线。中、高画质开启玩家车灯的遮挡阴影；低画质保留相同配光，关闭阴影以降低负担。湿路使用沥青底层与湿润反光层，雨雪中的受光保持轻微。灯组、配光纹理和雨雪着色均在本地生成。

## 模式和赛季

- **自由练习**：九条赛道均可选择，无圈数上限、不影响经济和积分。
- **计时挑战**：三圈计时；无复位才能进入纪录榜。纪录按路线版本、车辆、改装和驾驶辅助分别保存。
- **午夜锦标赛**：新赛季采用九站固定赛程，每站三圈、四名 AI 对手。路线分别为雨港仓道、灯市旧街、临江高架、钢火工业环、雾岬海岸、午夜城市环、松岚山径、赤岩峡谷、霜湖雪岭。各站布局、长度、弯道及场景不同。
- **两档基础难度 + 温和动态平衡**：街头为默认档，竞速档采用更积极的弯速和制动策略。锦标赛会根据近期表现缓慢调整对手，赛中节奏修正最多 ±3%，所有车辆继续执行原有物理、碰撞和检查点规则。

积分为 12 / 9 / 6 / 4 / 2，奖金为 2200 / 1800 / 1500 / 1250 / 1100。同分依次比较获胜站数、各站总名次和固定车手编号。玩家冲线时即结算；尚未冲线的对手按当时真实合法进度排序，避免等待。画面和规则中会明确区分本站第一、赛季冠军和未夺冠完赛。

三款原创车辆是隼 S1、脉冲 GT 和重岳 V8，分别偏向轻量敏捷、均衡稳定与高速重型。隼为免费初始车且可完成整季，GT 售价 4500，V8 售价 6500。初始余额 1200。动力、雨地轮胎、转向悬挂、氮气四类改装各有三级，影响真实物理参数。车辆和改装不转卖、不退款，切换车辆保留调校。

只有按正确方向依次通过 32 个检查点后再穿越终线才完成一圈。排名使用合法检查点及所在区间的进度。逆行、跳检查点、蹭终线和复位不能增加圈数。车身使用定向矩形碰撞体；轮胎抓地、速度、横向速度、车身角度与碰撞冲量共同决定运动。

安全复位回到最近合法检查点之后，不推进检查点，增加 **5 秒**，提供 **2 秒碰撞保护**，有 **5 秒冷却**。该次计时挑战不入榜，已有惩罚不会清零。有效漂移和干净的正向行驶补充氮气；低速、逆行和持续碰墙不产生漂移奖励。

重试本站会恢复本站发车前的金币、车辆和改装，撤销本站积分、奖金与赛后购买，不会重复刷奖励。新赛季重置赛程和积分，保留余额、车辆、改装、纪录与实力评估。未夺冠可以重试最后一站或开始新赛季。

## 自然赛道扩展

| 赛道 | 单圈长度 / 路宽 | 环境与驾驶条件 |
|---|---|---|
| 松岚山径 | 2.49 km / 22 m | 针叶林、起伏林地、山岩、细雨林雾；湿润柏油与连续中速弯 |
| 赤岩峡谷 | 2.72 km / 24 m | 暮色砂岩、台地、砂砾与仙人掌；干燥柏油、长直道与收紧回转 |
| 霜湖雪岭 | 2.57 km / 23 m | 积雪针叶林、雪山、凹陷冰湖和飘雪；低温柏油、长弧与回转 |

自然地形与湖岸由本地几何和 Canvas 纹理生成，道路两侧保留清晰的护栏及反光标。峡谷路面抓地系数为城市湿路的 1.07 倍、制动系数为 1.03 倍；雪岭分别为 0.88 和 0.94 倍。玩家与 AI 使用同一套路面规则，车辆自身改装参数不变。道路保持现有平面驾驶模型，山坡和山峰属于周边环境，不引入跳跃、坡度或越野物理。

更新前已开始或已完成的六站赛季仍沿原赛程结算，车辆、改装、金币、积分、纪录和动态实力继续保留；下一次开启新赛季时采用九站。三条新赛道在自由练习与计时中立即可选，无须等旧赛季结束。

## 温和动态平衡

锦标赛现在会记住最近 10 场已完成比赛，以近期名次、前后车差距和事故情况评估竞技水平。近期数据权重更高，切换难度、车辆、改装或驾驶辅助后，会降低旧条件下成绩的参考权重。单场实力分变化最多 4 分，对应 AI 目标节奏变化最多 0.024；长期目标节奏有明确上下限。标准档的初始对手也已加强，前 3 场界面显示“适应中”。

比赛中依据合法赛道进度估算差距：前后 2 秒内保持节奏，差距较大时用 12 秒时间常数平滑修正 AI 目标节奏，最大 ±3%。发车前 12 秒、玩家停车、撞墙、逆行、复位保护及复位后恢复期不继续拉动追赶；最后 180 米回归本场基础节奏。系统只改变 AI 的油门、制动、线路和氮气决策，玩家车辆参数保持不变，不修改车速、位置、赛道进度或计时。

玩家冲线立即结算，后车尚未完赛时用剩余合法距离和玩家本场平均行驶速度估算差距，界面标注“估算”。前车已经冲线时使用实际完赛时间差。赛后、赛前和设置中可以查看评估、对手节奏及调整原因。界面的 100% 指当前所选基础难度的目标节奏，不代表胜率或实际平均速度。

事故多的比赛降低学习权重；教学、自由练习、计时挑战和中途退出不训练难度。每次合法结算只学习一次；重试撤回奖金与积分，但保留已经完成的真实驾驶经验。几天不玩，实力偏离中值的部分每日保留 97%，缓慢回归中值；同一天反复打开游戏不会重复衰减。旧存档会补齐评估数据，保留车辆、改装、金币与赛季。

## 存档和暂停

独立存档键：`night-circuit.save.v1`，使用浏览器 localStorage，按浏览器和访问地址独立保存。购买、选择赛车、改装、结算、站次和设置自动保存。清除浏览器网站数据也会删除存档。

比赛中刷新不会恢复半场车辆坐标，而是返回当前站赛前状态；已完成各站的奖金和积分保留，并提示重新出发。损坏存档会尝试备份到相同前缀的 `.backup.<时间戳>` 键并提示新建进度。存储被浏览器拒绝时提示不能保存。

Esc、失焦、切后台和设备旋转会暂停并清理输入。暂停冻结玩家、AI、物理、倒计时、圈速和氮气；恢复有两秒准备时间。固定物理步长为 1/120 秒，渲染与模拟分离。长时间卡顿限制单帧追赶时长，避免恢复时跳过大段赛道；长任务下以实际执行的固定模拟时间计时，不保证与操作系统墙钟完全相等。

## 声音、画质与素材

首次点击后解锁 Web Audio。音乐由本地合成器生成，包含菜单氛围、比赛节奏和结算段落；车辆有随速度、负载和模拟换挡变化的引擎声，另有漂移、氮气、碰撞、倒数、过圈、购买和冲线音效。对手音量随距离衰减。音乐和音效独立调节。

雨夜使用反光车漆、环境映射、湿地材质、灯光倒影提示和雨滴，属于轻量程序化 3D 表现，不是照片级场景。低画质降低渲染分辨率、关闭动态阴影并减少雨滴与烟雾，不改变物理、AI 或规则。使用支持 WebGL 2 的现代浏览器，建议开启硬件加速。

### Cloudflare Pages

手机和平板的小地图宽度为 88–116px，保留与名次和转向区的空隙。氮气位于油门左上方，两轴至少各隔 20px；常规油门触控面积 96×64px，小高度横屏为 88×56px，方便同时按压油门与氮气。`browser-pedal-spacing.mjs` 使用真实触摸事件检查双指按压、松开氮气保留油门与取消输入；也可传入线上 URL 检查正式版布局。

驾驶 HUD 三端统一：小地图位于右上角计时栏下方，间隔 12–16px；时速位于底部中央，氮气表在其旁边或下方，紧凑横屏避让双手操作区。`browser-hud.mjs` 可传入生产 URL 验证五种视口。游戏用浏览器 `requestAnimationFrame` 驱动，不设固定 60 帧上限；120 Hz 固定物理与渲染插值分离，高刷新率下不会改变车速或比赛时间。根据持续帧负担逐级调整远景范围、天气数量和阴影更新频率，保留设定的像素比。实际帧率受 GPU、浏览器、电源设置和后台状态影响。

游戏图标全部保存在 `public`：`favicon.svg`、含 16/32/48/64/128/256 尺寸的 `favicon.ico`、`favicon-32.png`、`apple-touch-icon.png`、`icon-192.png` 和 `icon-512.png`。`node scripts/build-icons.mjs` 从矢量稿重新生成本地图标，构建后由本站提供。

赛车画面采用多重采样抗锯齿，并按画质提高实际绘制分辨率：低画质保持页面原生尺寸，中画质最高 1.75 倍，高画质触屏最高 2 倍、桌面最高 2.25 倍。普通 DPR 1 桌面中/高画质也分别启用 1.25/1.5 倍超采样；额外像素受中画质 300 万、高画质 600 万的总量限制，大屏最低保持页面原生分辨率。旋转、全屏、窗口缩放和设备像素密度变化时重新计算。高画质会增加 GPU 与电量消耗，可按设备选择；不重置已有画质设置。

生产站点：[https://mest-circuit.pages.dev/](https://mest-circuit.pages.dev/)。更新时先运行 `npm run build`，再执行 `npx wrangler pages deploy dist --project-name=mest-circuit`。`browser-map-spacing.mjs` 可传入站点 URL，对本地或已部署的手机/平板横屏布局做截图与间距检查。

`verify:season` 在原始 120 Hz 物理中只提供驾驶输入，合法跑完九站、发放奖金、升级轮胎、购买第二辆车并验证实际赛季结算；不改位置、性能、圈数、检查点或排名。`browser-season` 在真实时间的浏览器中通过键盘与指针事件驾驶，遥测接口只读。开发版的只读遥测不包含在生产版中。

实际测试结果、验证版本和局限见 `artifacts/TEST-REPORT.md`；截图在 `artifacts/screenshots`。设备视口模拟不等于实体手机验证。

核心源码：`physics.js` 驾驶与碰撞，`tracks.js` 路线，`ai.js` 驾驶控制器，`race.js` 检查点和比赛，`adaptive.js` 日常实力评估与温和动态平衡，`render.js` 车辆与场景，`headlights.js` 近光灯配光与降水受光，`input.js` 键盘与多点触控，`audio.js` 合成声音，`save.js` 进度与经济，`ui.js` 与 `style.css` 界面。

触屏操作区可在「设置 → 按钮透明度」调整 0%–80%，默认 0% 保留原有外观。数值越大，轮盘、左右按键和踏板的底色与边框越透明，文字与图标保持清晰；调整即时生效并自动保存。电脑端复位按钮位于左侧名次栏下方，手机和平板触控布局中位于转向轮盘上方并保留约 24px 间距，转向轮盘省略文字标题。`node scripts/browser-control-transparency.mjs` 验证布局、透明度范围、保存恢复及多点触控，也可传入生产站点 URL。
